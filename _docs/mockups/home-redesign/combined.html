Structure

What you'll see scrolling.

Above the fold: brand + streak chip, greet, and the start of the XP hero. Everything below is reached by scrolling — exactly one decision per zone.

Section order

  1. Brand row.Wordmark + day-streak chip. Same as A.
  2. Greet."Steady work this week. Show up again." Eyebrow line above (weekday · day count).
  3. XP hero card.From B. Streak + level rank + "Day N." display number + XP-to-next bar + this-week summary line.
  4. Today's Challenge start.From A. Specific prompt name, mode/level/duration meta, gold Begin button.
  5. Practice modes.From B. 2×2 mode card grid. "More modes ↓" expander for Pro / extras.
  6. Difficulty.From A. Quiet 5-tick bar with current rank + Starter/Expert·Pro labels.

Why this works

You answered "progress + start" as twin focus — the XP hero owns progress, the Begin button owns start, and they sit next to each other. Everything else is one-tap-away but not competing for attention. The 2×2 mode grid keeps modes as the recognizable picker users expect; the quiet difficulty bar replaces today's loud 5-card horizontal scroll.
